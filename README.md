## Description
JSMART is an Android application designed to help users learn JavaScript interactively. It provides lessons, quizzes, and AI-generated exercises with real-time feedback to enhance learning.

## Features
- JavaScript lessons
- Quizzes with scoring
- Exercise with AI personalized feedback
- User authentication via Firebase
- Profile management
- Certificate
  
## Technologies
- Kotlin
- Android Studio
- Firebase Authentication & Firestore
- Cloudinary (for profile pictures)
- UCrop Library
- ArmDeveloper Codeview
- Jdoodle 
- Gemini API (for assessment feedback)
